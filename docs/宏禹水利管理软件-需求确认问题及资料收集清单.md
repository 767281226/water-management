## 第一部分 需求确认问题

### 一、基本信息与使用范围

| 编号 | 问题 | 优先级 | 我方建议 | 客户答复 |
|---|---|---|---|---|
| A1 | 系统使用人数大约多少？有几个部门？各部门的负责人是谁？ | 高 | 请提供组织架构和人员名单（见资料清单 M1） | |
| A2 | 手机端采用哪种形式？□ 手机浏览器 H5 页面　□ 企业微信内使用　□ 钉钉内使用　□ 独立 App | 高 | H5 页面，可同时放进企业微信（成本最低，不需要安装） | |
| A3 | 公司目前是否在使用企业微信或钉钉？ | 高 | 如果在用，建议用它推送填报提醒和审批通知 | |
| A4 | 员工外出（工地、出差、在家）时是否需要使用系统？还是只在公司内网使用？ | 高 | 支持外网访问（需要公网 IP / 域名，详见第三部分） | |
| A5 | 登录账号用什么？□ 工号　□ 手机号　□ 其他：____ 是否需要短信验证码登录？ | 中 | 工号 + 密码；外网登录时加图形验证码 | |
| A6 | 期望什么时候上线？是否接受分期上线（先上周报和资料，后上考评）？ | 高 | 分三期，见需求说明书第 7 章 | |
| A7 | 是否需要和公司现有系统对接（OA、财务、考勤等）？是否有历史数据要导入（历史周报、考评记录、项目清单）？ | 中 | 一期只导入人员和项目清单 | |

### 二、项目管理 —— 周计划 / 周完成情况

| 编号 | 问题 | 优先级 | 我方建议 | 客户答复 |
|---|---|---|---|---|
| B1 | 目前周计划表、周完成情况表是什么格式？请提供空白样表，以及近期 2~4 份真实填写的样例。 | 高 | 系统按现有表格设计，导出格式与现有表格保持一致（见资料清单 M2） | |
| B2 | 周报由谁来填？□ 每个员工各自填　□ 项目负责人按项目统一填　□ 两种都有 | 高 | 每个员工各自填，系统自动按项目汇总 | |
| B3 | 周计划需要填哪些内容？原型里是：项目、工作内容、计划目标、计划工时（天）、备注。是否需要增删？ | 高 | 按样表确定 | |
| B4 | 周完成情况需要填哪些内容？原型里是：完成比例、实际完成内容、实际工时、未完成原因、计划外工作。是否要上传成果附件？ | 中 | 附件选填 | |
| B5 | 工时按"天"还是按"小时"填写？ | 中 | 按天，精确到 0.5 天 | |
| B6 | 填报截止时间？逾期怎么处理（只标记 / 扣考评分 / 通报）？周一或周五是节假日时如何处理？ | 中 | 周一、周五 23:59 截止；逾期标记并计入考评；节假日顺延到下一个工作日 | |
| B7 | 会议、投标、培训等非项目工作是否也要填？ | 中 | 需要填，归入"其他工作" | |
| B8 | 谁查看周报？是否需要点评、退回？部门是否需要把汇总周报再报给公司领导？ | 中 | 部门负责人查看并点评，可以退回；领导查看全公司 | |
| B9 | 员工能否看到同部门其他人的周报？ | 低 | 不能，只能看自己的 | |

### 四、月度考评与年度汇总

| 编号 | 问题 | 优先级 | 我方建议 | 客户答复 |
|---|---|---|---|---|
| D1 | 公司目前有没有项目考核或绩效考核办法？请提供文件和打分表样例。 | 高 | 系统按现行办法设计（见资料清单 M4） | |
| D2 | 月度打分有哪些指标，各占多少权重？ | 高 | 进度 30%、质量 40%、工作量与难度 20%、客户评价 10%（可配置） | |
| D3 | 谁打分？□ 部门负责人　□ 多人打分取平均　□ 部门打分后领导复核 | 高 | 部门负责人打分，公司领导审核发布 | |
| D4 | 是只给项目打分，还是要把项目得分分配到个人？如果分配到个人，按什么规则分配（工时占比 / 负责人指定比例）？ | 高 | 按工时占比分配，负责人可以调整 | |
| D5 | 考评结果对谁公开？员工能否看到他人的得分和排名？ | 中 | 员工只能看到自己参与的项目得分；排名只有管理层能看 | |
| D6 | 年度汇总需要哪些报表？是否与年终绩效或奖金挂钩？请提供现有的年度汇总表样例。 | 中 | 个人、项目、部门三张汇总表，可导出 Excel / PDF | |

### 五、资料中心与下载审批

| 编号 | 问题 | 优先级 | 我方建议 | 客户答复 |
|---|---|---|---|---|
| E1 | 资料如何分类？原型里分为"相关规范 / 公司成果 / 行业资料"，是否与网盘目录一致？ | 高 | 按网盘现有目录结构（见资料清单 M6） | |
| E2 | 资料规模有多大：文件数量、总容量、单个文件最大多少？主要是什么格式（PDF、Word、Excel、CAD 图纸、压缩包）？ | 高 | 用于确定存储方案和在线预览方案 | |
| E3 | **下载审批流程**：谁审批？分几级？是否按资料密级区分？请提供现行的资料借阅 / 下载制度或审批单（如有）。 | 高 | 公开 / 内部资料由部门负责人审批；涉密资料由部门负责人 + 公司领导两级审批（见资料清单 M5） | |
| E4 | 是否有资料可以免审批直接下载（如公开发布的国家规范）？ | 中 | 公开规范免审批 | |
| E5 | 审批人不在时怎么办？是否需要设置代理审批人？审批超时是否提醒？ | 低 | 支持设置代理人；超过 24 小时提醒 | |
| E6 | 审批通过后的下载限制：有效期多久？最多下载几次？ | 低 | 7 天内有效，最多 3 次 | |
| E7 | 资料由谁负责更新？多久更新一次？员工能否自己上传资料（如项目成果归档）？ | 中 | 资料管理员负责，每月更新；员工上传需审核 | |
| E8 | 是否需要搜索文件内容（全文检索），还是只搜索文件名和编号？ | 中 | 一期搜索文件名和编号，全文检索放在后期 | |
| E9 | 在线预览是否需要水印、禁止截屏等防泄密措施？ | 中 | 加"姓名 + 工号 + 日期"水印 | |
