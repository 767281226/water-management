## 1. 项目概述

### 1.1 建设背景
宏禹公司是水利行业的设计/咨询类企业，目前项目进度靠线下表格、微信群汇报，统计考核工作量大；公司内部资料分散在内部网盘里，员工查找不方便，下载也没有管控。

### 1.2 建设目标
1. **项目管理规范化**：固定"周一报计划、周五报完成"的周报节奏，月度对存档项目统计打分，年度自动汇总，减少人工统计。
2. **资料共享与管控**：统一入口查询、浏览公司内部资料，下载走审批，留痕可追溯。
3. **随时随地使用**：PC 和手机都能用。

### 1.3 使用范围
- 只供公司内部使用，不对外开放。
- 员工使用**账号 + 密码**登录；账号由管理员统一开通，不开放自助注册。
- 使用终端：**电脑端（浏览器）+ 手机端**。
  - 【待确认】手机端形式：方案 A 用手机浏览器访问的 H5 页面（推荐，成本最低）；方案 B 企业微信/钉钉内嵌应用；方案 C 独立 App。

## 2. 用户角色

| 角色 | 说明 | 主要权限 |
|---|---|---|
| 普通员工 | 公司全体员工 | 填报周计划 / 周完成情况；查看自己的考评结果；浏览资料；申请下载 |
| 部门负责人 / 项目负责人【待确认】 | 部门经理、项目经理 | 员工的全部权限，另外可以查看本部门的周报和填报情况、给存档项目打分、审批本部门的下载申请 |
| 公司领导【待确认】 | 总经理、分管领导 | 查看全公司的周报、考评、年度汇总；对敏感资料做终审 |
| 资料管理员 | 行政/技术管理部 | 维护资料分类，上传、更新、下架资料，同步网盘 |
| 系统管理员 | 信息化负责人 | 管理账号、部门、角色权限，配置考评规则，维护系统参数 |

> 一个人可以同时有多个角色。

#### 3.3.5 月度考评（存档项目统计打分）

> 原始需求："每月对存档项目进行统计打分"。下面的打分细则是建议方案，**需要客户提供或确认公司现行的考核办法**。

| 编号 | 功能 | 描述 |

| F-342 | 打分指标（建议） | 进度完成情况 30%、成果质量 40%、工作量/难度 20%、客户评价 10%（总分 100 分）；指标和权重可以在后台配置 |

| F-347 | 考评锁定 | 发布后锁定，不能再修改；如需更正，由管理员解锁并留下日志 |

```
周一 09:00 系统提醒 ─► 员工填报本周计划 ─► 提交 ─► 部门负责人查看/点评（可退回）
```

## 5. 非功能需求

### 5.1 性能与容量
- 用户规模：约 ___ 人【待确认】，同时在线 ≤ 100 人。
- 页面打开时间 ≤ 2 秒；资料搜索 ≤ 3 秒。
- 资料存储量：约 ___ GB【待确认，以现有网盘容量为准】。

### 5.2 与内部网盘对接【待确认】
| 方案 | 说明 | 优缺点 |
|---|---|---|
| A. 直接读网盘目录（推荐） | 系统通过 SMB/WebDAV/网盘 API 读取指定目录，资料仍然存在网盘里，系统只建索引并控制权限 | 不用重复存储；需要网盘支持相应协议 |
| B. 导入系统存储 | 资料管理员把网盘文件导入系统，以后统一在系统里维护 | 管控最严；需要额外存储空间，网盘和系统要同步 |
| C. 混合 | 规范类资料走网盘目录，成果类资料导入系统 | 灵活；实施稍复杂 |

> 请提供：网盘品牌/型号（如群晖、威联通、自建 NextCloud、企业网盘等）、访问协议、目录结构。

### 5.3 安全
- 只能在公司内网访问，还是外网也能访问？【待确认】需要外网访问时建议 HTTPS + 登录验证码，可选 VPN。
- 密码加密存储；会话超时 30 分钟后自动退出（PC）。
- 资料预览加水印，禁止右键另存；下载全程留日志。
- 数据每日自动备份，至少保留 30 天。

### 5.4 兼容性
- PC：Chrome、Edge、360 浏览器（极速模式）最新版本。
- 手机：iOS 14+、Android 9+ 的主流浏览器或微信内置浏览器。
- 页面自适应，手机端用底部导航，操作针对单手使用优化。

### 5.5 部署【待确认】
- 方案 A：部署在公司内部服务器（推荐，和网盘同一个内网）。
- 方案 B：云服务器部署。

## 6. 数据字典（核心）

**项目（Project）**：项目编号、名称、类型、委托单位、负责人、参与人员、部门、开始日期、计划完成日期、实际完成日期、状态、存档日期。

**周计划（WeeklyPlan）**：填报人、年份、周次、提交时间、是否逾期、状态；明细：项目、工作内容、计划目标、计划工时、备注。

**周完成情况（WeeklyReport）**：关联周计划；明细：完成比例、实际内容、实际工时、未完成原因；计划外工作；本周完成率。

**月度考评（MonthlyScore）**：考评月份、项目、打分人、各指标得分、总分、评语、状态（待打分 / 已打分 / 已发布）。

**资料（Document）**：名称、分类、编号（如 SL 252-2017）、版本、年份、密级（公开/内部/涉密）、是否需要审批、文件路径、大小、上传人、上传时间、浏览量、下载量。

**下载申请（DownloadRequest）**：申请人、资料清单、用途、申请时间、审批节点、审批人、审批意见、状态、有效期、已下载次数。
